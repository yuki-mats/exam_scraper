# Goal: 1995年（第3回）はり師きゅう師国家試験 4層パッチ手動整備と品質監査

## 目的
1995年（第3回）はり師きゅう師国家試験（全160問）について、1問ずつの医学的根拠に基づく目視精査と4層パッチ整備を完遂し、公式チェッカー全項目合格および取得元データ完全不変性を達成する。

## 対象範囲
- 資格: はり師きゅう師（`shinkyu`）
- 年度: 1995年（第3回）
- 総問題数: 160問（全7ファイル）

## 整備対象パッチ層
1. `10_questionType_fixed`
2. `15_correctChoiceText_fixed`
3. `23_correctChoiceText_fixed`
4. `21_explanationText_added`

## 品質基準
- 文化庁「公用文作成の考え方」準拠
- 各選択肢解説の文頭を「正しい。」「間違い。」で統一
- 4種公式チェッカーカバレッジ100%合格
- `00_source` の完全不変性維持
