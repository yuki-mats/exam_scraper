## 4. 目視精査方針
- 機械的一括自動生成・置換スクリプトを厳禁とし、1問ずつ問題文・全選択肢・公式解答を目視精査する。
- 文頭結論先行（「正しい。」「間違い。」）、自然な主語（法令名・条文名を文頭主語にしない）、重複表現排除（文化庁「公用文作成の考え方」準拠）。
- 否定設問における正誤判定の統一（断片肢否定設問は正解肢を「間違い」、他肢を「正しい」とし、変更メタデータを記録）。
- 関係法規問題における正確な条文・制度根拠の紐付け。
- 各ファイル完了ごとに4種の公式チェッカー（10, 15, 23, 21）および不変性検査（`check_00_source_immutability.py --check-staged`）を実行し、mainブランチへ直接コミット・pushする。
