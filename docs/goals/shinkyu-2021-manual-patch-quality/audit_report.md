## 2. 適用した品質基準と達成状況

1. **`00_source` の絶対不変性保護**:
   - 生データディレクトリ（`output/shinkyu/questions_json/2021/00_source/`）内のファイルは一切変更せず、すべての修正・拡張をパッチ層へ分離。
   - `python3 scripts/check/check_00_source_immutability.py` による検証を全コミットで合格。

2. **questionIntent の統一適用**:
   - 単純選択肢（語句・用語選択）の否定設問（「〜でないのはどれか」「〜ないのはどれか」）は、選択肢単体では真偽が定義できないため、すべて `questionIntent: select_correct` を適用。
   - 文章肢の正誤判定設問（「誤っているのはどれか」「適切でないのはどれか」など）は `questionIntent: select_incorrect` を正しく適用。

3. **日本語解説の最高水準推敲**:
   - 文化庁「公用文作成の考え方」に則り、文頭で直ちに結論（「正しい。」「間違い。」）を明示。
   - 法令名や資料名を主語に置かず、対象となる制度や規定、解剖組織、病態を自然な主語として構成。
   - 冗長な反復（「〜である点が誤り」など）を排し、簡潔で受験者の理解に直結する解説文を作成。
