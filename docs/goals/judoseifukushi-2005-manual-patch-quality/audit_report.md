## 3. 品質基準・個別検証の準拠結果

1. **出題形式と複数正答（`10_questionType_fixed`）**:
   - 複数正答問題（「2つ選べ」計38問）について、`questionType: "flash_card"` を確実に適用。
   - 単一正答問題（計192問）について、`questionType: "true_false"` を適用。

2. **設問意図の統一（`15_correctChoiceText_fixed`）**:
   - 誤りを直接選択させる設問（「誤っているのはどれか」「〜でないのはどれか」計50問）について、`questionIntent: "select_incorrect"` を適用。
   - 断片肢の否定設問（「〜をきたさない疾患はどれか」等）および通常設問について、`questionIntent: "select_correct"` を厳格適用。

3. **関係法規・法令コンテキスト（`18_law_context_prepared`）**:
   - 関係法規設問（柔道整復師法、医療法、保助看法国試関連）について `isLawRelated: True` とし、正確な条文・制度コンテキストを付与。
   - 医学・外傷学設問について `isLawRelated: False`, `lawGroundedExplanationNotNeeded: True` を整備。

4. **日本語品質・解説水準（`21_explanationText_added`）**:
   - 文化庁基準に基づき、各肢文頭に結論（「正しい。」「間違い。」）を明記。
   - 法令名を不自然に主語とせず、人・制度・病態・用語を自然な主語としたわかりやすい解説文を完備。
   - `lawReferences` は空配列 `[[], [], [], []]` の最新仕様を厳守。

5. **正答判定（`23_correctChoiceText_fixed`）**:
   - 公式解答および目視精査結果に基づき、各選択肢の正誤（「正しい」「間違い」）を完全整備。

6. **不変性検証（`00_source`）**:
   - `00_source` への変更・破壊・差分ゼロを完全維持。
