## 3. 整備手順
1. 各ファイル（約25問）について `dump` スクリプトで全問の問題文・選択肢・正解を出力。
2. 1問ずつ問題文・全選択肢・公式正答・医学的法令的根拠を目視精査（複数正答の検出、文頭結論「正しい。」「間違い。」の徹底、法令名文頭主語の排除）。
3. パッチ生成スクリプト（`10_questionType`, `15_questionIntent`, `18_law_context`, `21_explanationText`, `23_correctChoiceText`）を作成・実行。
4. カバレッジチェッカー・不変性チェッカーで完全合格を検証。
5. `state.yaml` を更新し、`main` ブランチへコミット・プッシュ。
6. 全10ファイル完了後、全230問一括検証・監査報告書を作成してゴール完了判定。
