## 3. 特記事項
- **複数正答（`flash_card`）20問**: 2006年は複数正答問題（2つ選べ）が計20問（問39, 108, 117, 119, 122, 123, 124, 127, 156, 175, 176, 179, 182, 186, 188, 191, 203, 205, 210, 220）存在し、すべて `questionType: "flash_card"`、正解肢・非正解肢判定を明記した解説、および空の法令参照構造を整備。
- **関係法規設問（10問）**: 午前問題の問1〜問10について、柔道整復師法、医療法、医師法、刑法、生活保護法、個人情報保護法等の根拠条文・制度背景を厳密に紐付け。
- **否定問題の意図・判定の統一**: 単語・断片肢の否定設問（「〜でないのはどれか」）は `questionIntent: "select_correct"` として正答肢に「正しい」、文形式の否定設問（「誤っているのはどれか」）は `questionIntent: "select_incorrect"` として各記述の真偽に応じた判定を徹底。
- **日本語品質**: 文化庁「公用文作成の考え方」に準拠し、文頭結論先行（「正しい。」「間違い。」）、実質的主語の明示、法令名文頭主語の排除を徹底。
- **00_sourceの不可変性**: スナップショットの完全同一性を維持（差分ゼロ）。
