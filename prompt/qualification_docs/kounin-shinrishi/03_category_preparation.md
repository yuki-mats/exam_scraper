# 公認心理師：既存分類の境界

## 適用範囲と根拠

通常04が、問題本文と全選択肢から問題全体の主な復習先を一つ選ぶための境界資料です。既存の分類ID、名称、親子関係を維持し、分類の新設、全資格の再設計、肢別分類の同期、Firestoreのカテゴリ更新は行いません。

- 分類正本：[category.json](../../../output/kounin-shinrishi/category/category.json)。既存24フォルダ・75問題集の定義を使用します。
- 共通判断：[04の判断手順](../../04_prompt_link_questionSetId.md)と[分類方針](../category_taxonomy_policy.md)。
- 法令上の区別：[公認心理師法](https://laws.e-gov.go.jp/law/427AC1000000068)の第2条（定義における業務の列挙）と第42条第1項（関係者等との連携）。定義上の業務と、業務に当たる際に守る義務を区別します。

既存分類を作成した当初の専門家資料・Git由来は未確認です。この資料は新たな専門家taxonomyの採用を主張せず、現在の分類名・descriptionと法令上の区別に基づき、下記の近接分類の境界だけを明示します。件数は本番の最新値とは扱いません。

## 職責に関する近接分類

いずれも既存の`folder01_shokuseki`配下です。

| 既存の問題集 | 問題全体の主な復習論点 | 境界 |
| --- | --- | --- |
| `qs01_01_role` 公認心理師の役割 | 公認心理師法上の定義、資格の役割、定義に列挙された業務の範囲 | descriptionの「公認心理師法」「公認心理師の定義」に対応する。ある行為が定義上の列挙に含まれるか、含まれないかを識別する問題も含む。 |
| `qs01_02_duty_ethics` 公認心理師の法的義務及び倫理 | 業務に当たる者が守る義務、関係者との連携、倫理上の判断 | descriptionにある義務・倫理の内容、適用条件、適切な行動そのものを問う場合。別の範囲に含まれない理由として義務の名称が一肢に登場するだけでは、問題全体をここへ移さない。 |
| `qs01_05_field_work` 保健医療、福祉、教育その他の分野における公認心理師の具体的な業務 | 保健医療・福祉・教育等の場面で、心理検査、アセスメント、心理療法等を具体的にどう実施するか | 定義の列挙との所属関係だけを問う場合と、具体的な支援・実践の判断を区別する。 |

## 判断手順

1. 問題本文の限定（定義、条文、義務、実践場面等）を読み、全選択肢を通じて受験者が識別すべき関係を言語化します。
2. 正答肢だけでなく、他の全選択肢もその関係から説明できる分類を比較します。「含まれないもの」を選ぶ問題では、その除外肢の固有語だけを主題へ置き換えません。
3. 義務の内容や適用の適否自体が問われる場合は、定義の語が含まれていても義務・倫理の分類を検討します。条番号や一語だけで固定しません。
4. 分類正本のdescriptionと問題全体の決定要因が一致する場合だけ確定します。複数の独立した論点が同程度に残る、又はこの境界と分類正本が矛盾する場合は、通常04のholdと03c再確認へ戻します。

この資料は個別の問題番号・既存公開値・期待する判定結果を根拠にしません。正式保存と公開には、その都度の実入力固定、独立監査、検証、限定公開、反映確認が必要です。
