# 二級土木施工管理技士試験 補助ドキュメント

このディレクトリには、二級土木施工管理技士試験に固有の試験構造、カテゴリ設計資料、法令スコープを置きます。解説文の書き方は全資格共通の`prompt/03_prompt_add_explanationText.md`を使います。

## 資料

- `01_exam_profile.md`: 章立て、年度別の形式差、出題タイプ、取得データ固有の構造
- `03_category_preparation.md`: `category.json`を設計又は見直す場合の資料
- `04_law_reference_policy.md`: 通常確認する法令・公的基準の範囲

工程03では、法令問題の根拠範囲が必要な場合だけ`04_law_reference_policy.md`を追加参照します。category整備は`category.json`を先に使い、不足する場合だけ`03_category_preparation.md`を読みます。

これらは、取得済み`00_source`、保存済み`question_images`、`output/2nd-class-doboku-sekou/category/category.json`、ユーザー提供PDFを基に整理しています。
