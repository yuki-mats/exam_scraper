# 給水装置工事主任技術者試験 補助ドキュメント

このディレクトリには、給水装置工事主任技術者試験に固有の章立て、問題形式、カテゴリ設計資料を置きます。解説文の書き方は全資格共通の`prompt/03_prompt_add_explanationText.md`を使います。

## 資料

- `01_exam_profile.md`: 章立て、出題数の偏り、問題形式、取得データ固有の構造
- `03_category_preparation.md`: `category.json`を設計又は見直す場合の資料

## 解説の資格固有調整

- 水道事業者、都道府県知事、指定給水装置工事事業者、主任技術者などの主体、直結式と受水槽式、性能基準とシステム基準を区別し、その問題で正誤を分ける役割・条件・順序を示す。

資料はユーザー提供の参考書、過去問、章扉、目次、解説ページ写真を基に整理しています。日常の`questionSetId`紐付けは`category.json`を正本とします。
