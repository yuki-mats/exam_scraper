# 03c カテゴリ設計メモ

## 根拠

- 厚生労働省「第55回建築物環境衛生管理技術者試験の合格発表」
  - https://www.mhlw.go.jp/stf/newpage_65584.html
- `output/birukan/questions_json/*/00_source/`
  - 2018年度（第48回）から2025年度（第55回）までの8年度分。
  - 各年度の出題ラベルは、建築物衛生行政概論、建築物の構造概論、建築物の環境衛生、空気環境の調整、給水及び排水の管理、清掃、ねずみ、昆虫等の防除の7科目に対応する。

厚生労働省の公式科目を資格全体の上位分類とし、年度・回・問題番号では分類しない。公式科目とfolderは1対1に対応するため、公式上位分類を複数folderへ分割するための対応表は不要だが、category.jsonには監査用の1対1対応を記録する。

## 境界

- 建築物衛生行政概論は、制度、行政、管理体制、公衆衛生の基礎を扱う。個別設備の測定・運転・維持管理は各設備科目へ置く。
- 建築物の構造概論は、建築構造・材料、建築環境、建築設備の基礎を扱う。空調、給排水などの専門的な管理は各専門科目へ置く。
- 建築物の環境衛生は、人体・健康と環境要因、環境衛生管理の一般論を扱う。空気環境、給排水、防除の専門技術は各科目へ置く。
- 空気環境の調整は、換気・空気調和、空気環境測定、空調設備の維持管理を扱う。建築物全般の熱・湿気は建築環境へ置く。
- 給水及び排水の管理は、給水・給湯、排水・通気、水質・水設備の維持管理を扱う。水質を含む環境衛生の一般論は建築物の環境衛生へ置く。
- 清掃は、清掃作業、清掃用機械・資材、廃棄物、清掃計画・管理を扱う。ねずみ・衛生害虫の防除は防除科目へ置く。
- ねずみ、昆虫等の防除は、生態、発生調査、防除方法、薬剤・安全管理を扱う。通常の清掃作業は清掃科目へ置く。

questionSetは、同じ科目内で復習先を分ける必要がある頻出論点の単位とした。既存のcategory.jsonは空で既存IDがないため、今回の新規IDを採用する。問題へのquestionSetId付与とquestionCountの確定は04工程で行い、03cでは問題側成果物を作成しない。
