# 建築物環境衛生管理技術者

資格コードは`birukan`です。公式問題と正答を出題時判定の正本とし、取得元の解説断片が相互に矛盾する場合は公式資料と公的一次資料へ戻ります。

## 解説の資格固有調整

- 特定建築物のねずみ等の防除で承認済みの医薬品又は医薬部外品を用いる根拠は、建築物衛生法施行規則第4条の5第2項第2号です。第4条の4は防除対象となる動物の定義であり、薬剤要件の根拠にしません。
- 給湯循環ポンプの背圧を吐出圧と同一視しません。公式問題で「吐出し側にかかる圧力」とする肢が誤答なら、その公式正答を保持し、相反する取得元解説だけで反転しません。
- 中央式給湯の循環系と、空調用の閉じた冷温水循環系を混同しません。中央式給湯では給湯往管と返湯管の流量・管径が異なるため、リバースリターン方式を採用しても湯の均等循環には有効ではありません。空調用冷温水配管で経路抵抗をそろえる一般論を、この給湯系へそのまま移して正誤を反転しません。
