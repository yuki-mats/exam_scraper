# 公害防止管理者 試験プロフィール

この文書は、`kougai`（公害防止管理者試験）の出題構造、問題形式、科目・単元設計を整理する資格固有資料である。

## 全体像

- 対象は 2010〜2025 年度の公害防止管理者試験過去問（yaku-tik 取得分）である。
- canonical source は 16 年度 × 6 ファイル = 96 ファイル、計 2,160 問（各年度 135 問）で構成される。
- 問題形式（`questionType`）、計算問題フラグ（`isCalculationQuestion`）、設問意図（`questionIntent`）は、取得元の初期値や他問の形式を前提とせず、各問の問題文・図表・全選択肢から各工程の正本（`prompt/01_prompt_fix_questionType.md`、`prompt/02_prompt_add_questionIntent.md`）に従って一問ずつ独立に判定する。

## 出題構造と問題形式（工程01 `questionType` / `isCalculationQuestion`）

公害防止管理者試験には、以下の出題パターンが混在している。`prompt/01_prompt_fix_questionType.md`（v6.6）の判定基準に従い、問題の構造に応じて `true_false` / `flash_card` / `group_choice` と `isCalculationQuestion` を判定する。

1. **各選択肢が独立した命題となる正誤問題（`true_false`）**
   - 「〜に関する記述として、誤っているものはどれか（正しいものはどれか）」のように、選択肢 `(1)`〜`(5)` がそれぞれ独立した文になっており、1肢ずつ単体で正誤判定が成立する問題。
   - 空欄補充問題のうち、`00_source` 時点で「次の空欄と語句の対応が正しいか判定してください」として各空欄ペア（`ア：...`）に分解されている問題（複数正解を含むペア正誤判定）も `true_false` とする。
2. **計算問題・単一値や単一用語・定義式を直接導出する問題（`flash_card`）**
   - 数値計算によって唯一の値を求める計算問題、および「〜を表す式はどれか」「〜の物質はどれか」「〜のJIS規格における名称はどれか」のように、設問条件から単一の答えを直接思い出せる・導出できる問題。
   - 四則演算、対数計算（デシベル合成・距離減衰等）、化学反応の量論計算、収支計算、除去率・滞留時間・有効煙突高さ等の数値導出を行う問題は `isCalculationQuestion = true` とし、知識・定義・定性関係を問う問題は `isCalculationQuestion = false` とする。
3. **複数空欄の組合せ・下線部選択・順序配列・相対比較問題（`group_choice`）**
   - **下線部問題**: 「記述中、下線を付した箇所のうち、誤っているものはどれか」のように、段落内の下線箇所 `(1)`〜`(5)` や `(a)`〜`(j)` の正誤・組合せを問う問題。問題文全文に `(1)`〜`(5)` の文脈が揃っている状態で、選択肢全体を見比べて判断する `group_choice` とする。
   - **複数空欄・表・フロー図の組合せ問題**: `(ア)`〜`(オ)` や図中の `(A)`〜`(D)` に入る語句・数値・化学式の組合せを `(1)`〜`(5)` から選ぶ問題。
   - **順序配列・相対比較問題**: 処理工程の順序、制定年の古い順、「最も適当なもの」「最も関係の薄いもの」など選択肢間の比較を要する問題。
   - ※例外として、本文中の `(ア)`〜`(オ)` のうち「誤っている（正しい）ものはいくつあるか」を問う個数選択問題は、集計回答整合性契約（`official_answer_alignment_issue`）との整合を保つため既存構造に合わせて扱う。

## データ整備上の注意

- **01 `questionType` / `isCalculationQuestion`**: 上記3分類と計算判定基準に従い、一問ずつ本文と選択肢を精査して判定する。下線部問題で本文と選択肢の分割が崩れている場合は、原文の段落全文と下線語句を正確に復元する。
- **02 `questionIntent`**: 「正しいものを選ぶ（計算・導出を含む）」（`select_correct`）か「誤っているもの・不適当なものを選ぶ」（`select_incorrect`）かを設問文から確定する。
- **03 `explanationText`**: `prompt/03_prompt_add_explanationText.md` に従い、受験ブログ調の主観表現（「捨て問題」「スルーでいい」等）や外部ページ参照誘導を排し、数式・反応式を LaTeX（`$...$` / `$$...$$`）で明示した自己完結した解説とする。
- **04 `questionSetId`**: 科目の大枠だけでなく、問題が扱う具体的な対象（例：騒音と振動の区別、大気拡散予測モデルと設備対策事例の区別、特定粉じん測定と一般粉じん対策の区別、汚泥処理・維持管理と物理化学処理の区別）を精査し、最も適切な `kougai_qs<folder番号>_<範囲番号>` に割り当てる。
