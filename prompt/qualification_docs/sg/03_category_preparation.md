# SG category.json 準備記録

## 分類の根拠

- IPA「情報セキュリティマネジメント試験 出題内容」
  - https://www.ipa.go.jp/shiken/kubun/sg/outline.html
- IPA「情報セキュリティマネジメント試験（レベル2）シラバス Ver.4.1」
  - https://www.ipa.go.jp/shiken/syllabus/nl10bi0000007tch-att/syllabus_sg_ver4_1.pdf
- 対象source
  - 2016〜2019年の午前・午後問題
  - 2023〜2026年の公開問題

現行シラバスは、科目Aで情報セキュリティを重点分野とし、ネットワーク、データベース、システム構成要素、プロジェクトマネジメント、サービスマネジメント、システム監査、システム戦略、システム企画、企業活動・法務を関連分野として整理している。科目Bは「情報セキュリティマネジメントの計画・要求事項」と「情報セキュリティマネジメントの運用・継続的改善」を大項目としている。

そこで、`category.json` のfolderは学習者が最初に選ぶ5領域に整理し、questionSetは対象sourceの旧分類と現行シラバスの実践領域を対応させた。午前問題の旧分類は名称を大きく変更せず、同じ復習先へ継続して集約できるようにしている。

## folderの境界

| folder | 主な範囲 | 境界 |
| --- | --- | --- |
| 01_情報セキュリティ | 情報セキュリティ全般、管理、対策、実装技術、技術評価、科目Bの実践 | 法令の適用判断は05、一般ネットワークの仕組みは02、監査手続の独立性・証拠評価は03へ分ける |
| 02_テクノロジ | システム構成要素、データベース、ネットワーク | セキュリティ対策の選択や攻撃防御が決定要因なら01へ分ける |
| 03_マネジメント | プロジェクトマネジメント、サービスマネジメント、システム監査 | 情報セキュリティのインシデント管理や管理策が決定要因なら01へ分ける |
| 04_ストラテジ | システム戦略、システム企画、企業活動 | 法令・権利・労働・取引の法的判断が決定要因なら05へ分ける |
| 05_法務 | セキュリティ関連法規、知的財産権、労働・取引関連法規、その他法務 | 技術や管理策の説明で法的義務の適用判断を問わない問題は01〜04へ分ける |

## questionSetの境界

`1-1`〜`1-5` は科目Aの情報セキュリティ知識を、`1-6` と `1-7` は科目Bの技能領域を受け持つ。科目Bの問題で、計画・資産価値・リスク評価・要求事項の作成が中心なら`1-6`、資産台帳の維持、利用状況の監視、委託先管理、インシデント対応、教育、改善が中心なら`1-7`とする。

`2-1`〜`2-3`、`3-1`〜`3-3`、`4-1`〜`4-3`、`5-1`〜`5-4` はsourceの `category` の中分類・小分類を復習単位へ対応させた。問題に複数の用語が出る場合は、用語数ではなく正答を決定する要件・制約・判断軸が最も強いquestionSetを選ぶ。問題文だけで決められず、主題が同等のまま残る場合は推測で細分化しない。

## 更新境界

- この工程では資格単位のtaxonomyだけを更新する。
- 問題側の`questionSetId`、`folderId`、既存の問題ID、`00_source`は更新しない。
- `questionCount`は04の問題紐付け後に集計するため、初期値は0とする。
- merge、convert、upload-ready生成、Firestore反映は別工程とする。
