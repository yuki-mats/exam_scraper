# 介護福祉士試験 補助ドキュメント

このディレクトリには、介護福祉士試験に固有の新旧科目構成、取得データの問題形式、カテゴリ設計資料を置きます。事例・制度・身体知識を含む解説文の書き方は、全資格共通の`prompt/03_prompt_add_explanationText.md`を使います。

## 資料

- `01_exam_profile.md`: 新旧科目の対応、出題形式、取得データ固有の構造
- `03_category_preparation.md`: `category.json`を設計又は見直す場合の資料

## 解説の資格固有調整

- 事例問題は、本人の意思、自立支援、安全、現在の観察事実のうち、設問で優先する判断軸を具体的に示す。「尊重が大切」「安全に配慮する」だけの一般論にしない。
- 制度問題は、制度名だけでなく、実施主体、対象者、年齢や利用条件のどこで正誤が分かれるかを示す。

工程03は`00_source`を起点に確定済み正答と根拠を照合します。取得元の解説候補はそのまま採用せず、共通の八つの問題パターンに沿って再構成します。日常の`questionSetId`紐付けは`category.json`を正本とします。
