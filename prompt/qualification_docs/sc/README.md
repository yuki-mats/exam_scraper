# 情報処理安全確保支援士（sc）

取得元は[情報処理安全確保支援士ドットコム](https://www.sc-siken.com/sckakomon.php)。前身の情報セキュリティスペシャリストを含み、午前Ⅰと午前Ⅱを同じ年度・実施回の別問題として保持する。問題の同定には年度だけでなく、`examLabel`、`question_url`、`sourceRecordRef`を使う。

公式問題冊子・解答は`output/sc/official_pdfs/<listGroupId>/`に保存している。午前Ⅰはファイル名の`koudo_am1`、午前Ⅱは`sc_am2`を照合する。解説の共通基準は[工程03](../../03_prompt_add_explanationText.md)、法令の確認範囲は[法令参照方針](01_law_reference_policy.md)に従う。

## 解説の資格固有調整

- 状態遷移問題では、設問が求める入力条件をそのまま読み、表から遷移を追う。「条件を満たす列を受理する」という問いに「その条件以外の列を一切受理しない」という逆向きの条件を追加しない。初期状態が指定されない場合、まず全状態からの遷移を確認し、末尾の入力で到達状態が一意になるかを調べる。初期状態の欠如だけで解けないと判断しない。
- 同容量の媒体への領域割当てでは、空き領域と使用量を区別する。空き領域が最大の媒体は、その時点の累積使用量が最小の媒体である。要求ごとに累積量を更新し、同値時の優先順も適用する。最後の割当て先と総量の順位を混同しない。
- 表・図に必要な条件がある問題は、公式冊子と保存済みの問題画像を直視する。取得元解説は確認の手掛かりとして使い、図や公式解答と独立に照合する。
