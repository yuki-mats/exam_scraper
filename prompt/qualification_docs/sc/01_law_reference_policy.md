# scの法令・公的基準の確認

技術・計算・アルゴリズムの問題と、法令又は法令が参照する制度・基準の問題を、各選択肢の正誤根拠から区別する。参照のschemaと監査段階は共通02b・03bに従う。

## 財務報告の内部統制

金融庁の内部統制実施基準を明示した問題は、企業会計審議会の基準本文と、その基準を位置付ける府令を両方確認する。

- 法令：財務計算に関する書類その他の情報の適正性を確保するための体制に関する内閣府令。`lawId=419M60000002062`。本則第1条第5項が企業会計審議会の公表基準を評価・監査基準として位置付ける。基準の位置付けと、個々の統制の分類を分けて説明する。
- [e-Gov法令API](https://laws.e-gov.go.jp/api/2/law_data/419M60000002062)で現在施行版と出題時版を確認する。XML locatorは実際に取得した本文から確定し、改正ID・項番号を推測しない。
- [令和5年4月7日公表資料](https://www.fsa.go.jp/news/r4/sonota/20230407/20230407.html)の[別紙1](https://www.fsa.go.jp/news/r4/sonota/20230407/1.pdf)は、実施基準Ⅰ・2（3）ロの「ITに係る全般統制」「ITに係る業務処理統制」を確認する資料である。PDF58〜59ページ（本文53〜54ページ）に分類と具体例がある。これは府令の条文とは別の資料であり、府令のXML locatorをこのPDF内の記述へ流用しない。
- 組織共通の方針・環境整備と、個々の業務システムへ組み込む処理の統制を区別し、各選択肢を基準本文へ対応させる。
- PDF本文を確認できていても、構造化できない根拠の`refs`や`displayRefIds`は推測で埋めない。確認資料と分類理由を共通schemaが許す説明・根拠要約へ残す。

## その他の法令問題

問題文・各選択肢と既存の根拠候補から対象法令を限定し、法令名、lawId、条・項・号と規律対象が一致する一次本文を確認する。情報セキュリティという資格名だけで広い法令を自動的に紐付けず、技術用語が条文にも現れるという理由だけで法令関連にしない。
