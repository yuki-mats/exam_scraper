このディレクトリには、`kashikin`に固有の試験構造と法令参照範囲を置きます。解説文の書き方と計算式の契約は、全資格共通の`prompt/03_prompt_add_explanationText.md`を使います。

## 対象データ

- 資格コード: `kashikin`
- 取得元: `output/kashikin/questions_json`
- 現在の取得範囲: 2015〜2025年、547問
- 問題取得元: `kashikin.kakomonn.com`
- 問題・正答の照合先: 日本貸金業協会が公開する公式試験問題と正答
- 試験日の正本: `document/sources/kashikin/official_exam_pdf_catalog.json`

`00_source`は取得時のスナップショットとして変更しません。掲載サイトの解説は探索材料に限り、正答又は法令根拠は、公式試験資料、e-Gov法令検索、金融庁等の一次情報で確認します。

## 解説の資格固有調整

- 「貸金業者の登録」と「貸金業務取扱主任者の主任者登録」は、主体、手続及び拒否事由が異なるため、問題文の主語から先に区別する。
- 金額、残高、期間又は比率が正誤を分ける問題は、その数値を法令上の条件として確認する。`isCalculationQuestion=true`の既存解説が有効な数式を持つ場合、法令監査で数式、数値代入、等号、途中計算又は結果を削除しない。
- 出題当時法令を確認できない場合は、現在の条文から過去の内容を推測しない。公式正答、確認済みの現行法根拠、不足する過去法令根拠を分けて記録し、必要なら`hold`にする。
