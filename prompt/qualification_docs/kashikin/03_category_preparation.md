# kashikin category.json 準備記録

## 根拠と対象範囲

この分類は、日本貸金業協会の公式試験科目区分、公式試験日に対応する2015〜2025年度の`00_source` 547問、及び`01_exam_profile.md`を根拠にした。`category.json`は資格全体の学習分類であり、年度・問題番号別の分類ではない。

公式の4領域は学習上の大分類として維持した。各領域の中は、過去問で繰り返し現れる法令・制度・財務諸表のまとまりを復習単位とし、法令名だけが共通する近接論点は、問題の主語と規律の目的で分けた。

## 境界ルール

- 貸金業者の登録・業務運営、貸付条件、返済能力調査、指定信用情報機関、書面・帳簿及び取立ては`01_法及び関係法令`に置く。
- 民法上の貸付取引、担保、保証、債権、倒産、手形及び犯罪収益移転防止法は`02_貸付けと付随取引の法令・実務`に置く。貸金業法上の債権譲渡・取立て規制は、民法の一般論と混同しないよう01に置く。
- 個人情報保護法、消費者契約法、景品表示法、日本貸金業協会の自主規制・紛争解決・貸付自粛は`03_資金需要者等の保護`に置く。貸金業法の広告表示事項や禁止行為そのものは01に置く。
- 企業会計原則、貸借対照表、損益計算書、キャッシュ・フロー計算書及び源泉徴収票は`04_財務及び会計`に置く。貸金業法上の年収証明書・返済能力調査は01に置く。
- 「信用情報」は、貸金業法上の照会・提供・同意義務を`1-9 指定信用情報機関`、個人情報保護法上の取得・安全管理・第三者提供を`3-1 個人情報・信用情報の保護`に分ける。
- 「広告」は、貸金業法の表示事項・禁止行為を`1-6`、景品表示法を`3-3`、協会の自主規制上の広告・勧誘を`3-4`に分ける。
- 「過剰貸付け」は、貸金業者が行う返済能力調査・法令上の除外・例外要件を`1-4`、利用者保護制度としての貸付自粛等を`3-6`に分ける。

## 03cで確定したこと

`category.json`には公式4領域と、その下で復習に使うquestionSetを登録した。03cでは問題ごとの`questionSetId`を付与しないため、すべての`questionCount`は0とした。問題側の紐付け、count集計、merge、convert及びupload-ready生成は04以降の責務である。

公式上位分類を別のfolderへ分割していないため、`metadata.officialCategoryMappings`は各公式領域と一つのfolderの対応を記録している。資格区分をfolderへ重複させる共有taxonomyには該当しない。
