# 貸金業務取扱主任者 試験プロフィール

この文書は、貸金業務取扱主任者資格試験の問題構造を判断するための資格固有資料です。

## 取得済み範囲

- `output/kashikin/questions_json`には、2015〜2025年の公式試験に対応する547問がある。
- 各年度は「法及び関係法令」「貸付け及び貸付けに付随する取引に関する法令及び実務」「資金需要者等の保護」「財務及び会計」の四領域で構成される。
- 公式の試験日とlist groupの対応は`document/sources/kashikin/official_exam_pdf_catalog.json`を使う。試験日を法令の基準日と無条件に同一視せず、年度別の公式資料に別の基準日があれば、その日付を優先する。

## 問題形式

- 単一選択の問題でも、アプリでは各記述肢を`正しい`又は`間違い`として整備する。
- 「適切なもの」「適切でないもの」の向きは`questionIntent`へ保存し、各記述の真偽と混同しない。
- a〜dの正しい組合せ又は個数を選ぶ問題は、承認済み`aggregateAnswerDecomposition`がある場合だけ、原文spanに基づいて独立した記述へ分解する。
- 分解後の`correctChoiceText`は、元の組合せ肢の正誤配列を転記せず、公式正答が示すa〜dの組合せから各記述の真偽を確定する。

## 整備上の注意

- 貸金業法上の主体は、貸金業者、顧客、保証人、資金需要者等、指定信用情報機関及び貸金業務取扱主任者を区別する。
- 「登録」は、貸金業者の登録、主任者登録、指定信用情報機関等の指定を区別する。
- 50万円、100万円、1か月、2か月、30日、60日などの数値は、対象となる契約、主体、原則及び経過措置まで確認してから解説へ反映する。
