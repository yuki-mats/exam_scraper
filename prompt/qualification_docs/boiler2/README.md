# 二級ボイラー技士

資格コードは`boiler2`です。ボイラーの定義、取扱作業主任者の選任、構造規格及び技術知識を区別して整備します。

## 解説の資格固有調整

- ボイラー取扱作業主任者の選任区分は、ボイラー及び圧力容器安全規則第24条を直接根拠にします。第23条の就業制限と取り違えません。
- 貫流ボイラーの伝熱面積は第24条第2項の換算を適用します。電気ボイラーの電力換算は、出題時の20kWを1m²とする基準と、2023年12月18日以降の60kWを1m²とする現行基準を分けて説明します。
- 法改正で正誤が変わる場合は、出題時と現行法の扱いを明記し、三次確認後にだけ現行法向け正誤を確定します。
