# G検定

- 資格コード: `g-kentei`
- 取得元: Udemy講座 `g-tbyxpv`（6つの演習テスト、各100問）
- 試験範囲・分類の正本: [JDLA公式 G検定](https://www.jdla.org/certificate/general/)
- 問題形式と独自問題化: [試験概要](01_exam_profile.md)
- 分類: [カテゴリ準備](03_category_preparation.md)

取得元の問題は、共通の05工程で1問ずつ確認し、問題文又は選択肢を自然に微改変する。正答と各誤答の判断理由は維持する。

## 確認済みの取得元修正

- 演習問題①問6: 学習済みモデルを一律に特許対象外とは扱わない。[特許庁のAI関連技術に関する審査事例](https://www.jpo.go.jp/system/laws/rule/guideline/patent/ai_jirei.html)に従い、単なるパラメータセットの提示と、プログラムとして機能するモデルを区別する。05では選択肢2を前者に限定する。
- 演習問題①問42: オフライン強化学習は固定データから学び、学習中に環境で追加探索することを前提としない。[オフライン強化学習の研究レビュー](https://arxiv.org/abs/2005.01643)と[Conservative Q-Learningの論文](https://arxiv.org/abs/2006.04779)に基づき、取得元の「探索戦略が必要」という説明を採用せず、データにない行動の価値推定を問う選択肢へ修正する。
- 演習問題①問45: 取得元は一次関数 `y=ax+b` と、加法性・斉次性を満たす線形写像の性質を混同している。[UC Davisの線形代数教材](https://math.ucdavis.edu/~linear/linear-guest.pdf)で後者の定義を確認した。05では選択肢1を「入力と出力の変化量の関係」に修正し、選択肢3だけが誤答となるようにする。
- 演習問題①問70: 取得元は特許を受ける権利が常に発明者へ原始帰属すると説明するが、現行の特許法第35条第3項では、職務発明についてあらかじめ契約や勤務規則などで使用者に取得させると定めた場合、権利は発生時から使用者に帰属する。[特許庁の職務発明制度の概要](https://www.jpo.go.jp/system/patent/shutugan/shokumu/shokumu.html)に従い、05の正答肢にこの条件を加える。後続03の解説も同じ条件で作成する。
- 演習問題①問71: 取得元は「実際は陽性だが陰性と判定する誤り」の正解を偽陰性（2番）としつつ、正誤ラベルと`questionIntent`を逆に記録している。05では偽陰性だけを正しい選択肢とし、`select_correct`に修正する。
- 演習問題①問80: 取得元の4番は推論時にもドロップアウトを適用する手法と区別できない。[通常のドロップアウトの原論文](https://www.jmlr.org/papers/v15/srivastava14a.html)と[推論時のドロップアウトに関する研究](https://proceedings.mlr.press/v48/gal16.html)を踏まえ、05では「推論時にも無効化が必須」という誤りに限定する。
- 演習問題①問85: 取得元のBICの説明は対数尤度とペナルティの符号を曖昧にしている。[statsmodelsのBIC定義](https://www.statsmodels.org/v0.14.6/generated/statsmodels.tsa.statespace.mlemodel.MLEResults.info_criteria.html)に従い、05の選択肢1を「負の対数尤度にペナルティを加える」と表現する。
- 演習問題①問98: 生体情報は、本人を識別できるように変換した符号が個人識別符号に該当する。[個人情報保護委員会のガイドライン](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/)を確認し、05の設問では顔・指紋の特徴データにこの条件を明示する。
- 演習問題①問99: SegNetの復元処理は単純な逆畳み込み層だけで表せない。[SegNetの原論文](https://arxiv.org/abs/1511.00561)に基づき、05では畳み込み層を使うEncoder-Decoder構造として説明し、プーリングインデックスを用いる特徴を選択肢3で維持する。
- 演習問題②問5: 取得元の「CRISP-ML」は、この設問が説明するライフサイクルと品質保証の枠組みを示す原論文の名称「CRISP-ML(Q)」に合わせる。[原論文](https://arxiv.org/abs/2003.05155)に従い、05の設問では正式名称を使用する。
- 演習問題②問6: 取得元は「has-a」を全体と部分の関係ではないとするが、[W3CのpartOf/hasPartの説明](https://www.w3.org/2001/sw/BestPractices/OEP/SimplePartWhole/)では両者は逆向きの関係として使える。05では`has-a`を下位概念とする誤答肢へ修正し、`is-a`との違いを問う。
- 演習問題②問12: 取得元は個人識別符号一般とマイナンバーを含む特定個人情報の第三者提供を混同している。[個人情報保護委員会の番号法ガイドライン](https://www.ppc.go.jp/legal/policy/my_number_guideline_jigyosha/)では後者を番号法第19条の限定列挙に従って扱う。05の誤答肢を特定個人情報に限定し、本人の同意だけで自由に提供できるという誤りを明確にする。
- 演習問題②問21: SaaSは提供者のクラウド上のアプリケーションを利用する形態であり、利用者の端末へのインストール有無だけでは定義できない。[NISTのSaaS定義](https://csrc.nist.gov/glossary/term/Software_as_a_Service)に合わせて05の正答肢を修正する。
- 演習問題②問23: 総当たり探索は解が存在しない場合まで「必ず解を見つける」とは言えない。05の選択肢1では有限の候補集合内に解が存在する条件を明示する。
- 演習問題②問32: ウォード法では、クラスタ結合によるクラスタ内誤差平方和の増加が小さい組を選ぶ。05の正答肢は取得元の「分散が最も小さい」という曖昧な説明を、この結合基準に直す。
- 演習問題②問40: [文化庁のAIと著作権に関する考え方](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html)を踏まえ、05の3番は既存著作物との類似性と利用条件、4番は人の創作的関与がない自律的生成に限定する。後続03も学習データの著作権と生成物の利用リスクを混同しない。
- 演習問題②問46: 取得元の「完成しなければ報酬を請求できない」という断定は、[民法第634条](https://laws.e-gov.go.jp/law/129AC0000000089)の可分な部分に関する例外を含まない。05では[第632条](https://laws.e-gov.go.jp/law/129AC0000000089)の請負の定義を空欄で問い、正答肢を維持する。
- 演習問題②問63: [特許庁の職務発明制度の説明](https://www.jpo.go.jp/system/patent/shutugan/shokumu/shokumu.html)を踏まえ、使用者の業務範囲と従業員の職務との関係を正答肢2に明示する。正答肢3は事前の契約・勤務規則があれば発生時から使用者に権利が帰属し得るとし、「常に発明者に原則帰属」とは断定しない。
- 演習問題②問65: [経済産業省のデータ契約ガイドライン](https://www.meti.go.jp/shingikai/sankoshin/shomu_ryutsu/joho_keizai/it_rikatsuyo/pdf/011_s02_01.pdf)では、データ一般に所有権が生じるという整理をしていない。05ではデータの利用権限を契約等で定める点に寄せ、パーソナルデータの扱いは個人情報保護法の論点として区別する。
- 演習問題②問66: [個人情報保護委員会の第三者提供の説明](https://www.ppc.go.jp/all_faq_index/faq1-q7-2/)では同一事業者内の部署間共有は第三者提供に当たらない。[匿名加工情報のガイドライン](https://www.ppc.go.jp/personalinfo/legal/guidelines_anonymous/)では第三者提供時の公表等が必要である。05は本人同意だけで「自由に」提供できる、匿名加工情報には制限がないという過度な断定を修正する。
- 演習問題②問67: 取得元の正答肢と解説は、インタビューシステムを利用者への診断支援と説明している。エキスパートシステムの[知識獲得ツールに関する研究](https://www.sciencedirect.com/science/article/abs/pii/S0020737387800330)を踏まえ、05の正答肢を専門家へのインタビューを通じた知識ベース構築に直す。後続03は古い解説を踏襲しない。
- 演習問題②問69: エンコーダ・デコーダ型のSeq2Seqを固定長ベクトルへ限定しない。05では入力系列を別の系列へ変換する構造として問う。
- 演習問題②問75: [NIST AI RMFの評価・監視項目](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/)を踏まえ、取得元の時期依存の「監査の制度化が広がっている」を、運用中の評価と管理策の見直しに置き換える。内部担当以外の評価者の関与を不要とする3番は引き続き誤答である。
- 演習問題②問78: [KerasのEarlyStopping仕様](https://keras.io/api/callbacks/early_stopping/)には改善幅とpatienceの設定があるため、05の正答肢を「検証損失が改善しなくなった段階」にし、初回の増加で必ず止めるという断定を避ける。
- 演習問題②問79: 特異値分解の正答肢を、二つの直交行列と特異値からなる対角行列の積という形に明確化する。
- 演習問題②問81: BERTを用いるQAには文書内の回答箇所を抽出する形もある。[BERTを用いたオープンドメインQAの研究](https://arxiv.org/abs/1902.01718)などを踏まえ、取得元の「BERTで回答生成」を抽出の例へ直す。対象領域を限定したQAの説明も、参照文書の範囲を明示する。
- 演習問題②問84: [個人情報保護委員会の死者情報に関する説明](https://www.ppc.go.jp/all_faq_index/faq1-q1-21/)では、死者の情報が遺族など生存者の個人情報にも当たり得る。05の誤答肢は「死後はすべて自由」と断定せず、遺族の意向や故人の尊厳を無視してよいという倫理上の誤りを問う。
- 演習問題②問86: UCB方策は平均報酬だけではなく不確実性も使って上側信頼限界を評価する。05の3番をその選択基準に合わせて明確化する。
- 演習問題②問87: マージンは分類境界と最も近い訓練データとの距離であり、取得元の「分類器と訓練データの境界」という不正確な表現を直す。
- 演習問題②問90: [OpenAI公式のGPT-4oモデル資料](https://developers.openai.com/api/docs/models/gpt-4o)は、API上のGPT-4oにテキスト・画像入力を示し、音声・動画は非対応とする。05では音声・画像・動画の一体処理という取得元の断定を避け、2024年発表のモデル名を問う。
- 演習問題②問97: [特許庁の審査基準](https://www.jpo.go.jp/system/laws/rule/guideline/patent/tukujitu_kijun/)で新規性・進歩性・産業上の利用可能性を確認し、05ではこれらを「特許を受ける発明」に求められる主な要件として問う。これだけで必ず特許を取得できるとは書かない。
- 演習問題③問4: [Dennettのフレーム問題の例](https://www2.cs.sfu.ca/~vaughan/teaching/415/papers/dennett-cognitivewheels.html)を踏まえ、05の正答肢はロボットの行動によって変わることと変わらないことを判断しきれない点を明示する。取得元解説の「あり得ない事象まで考慮する」という説明へ戻さない。
- 演習問題③問5: [Transformerの原著論文](https://arxiv.org/abs/1706.03762)を踏まえ、05では再帰と畳み込みを使わずAttentionを中心に系列を処理する構造として問う。エンコーダとデコーダをAttentionだけで結ぶという取得元の曖昧な説明を避ける。
- 演習問題③問7: [個人情報保護委員会の個人情報と個人識別符号の説明](https://www.ppc.go.jp/personalinfo/faq/kojin/)および[携帯電話番号・クレジットカード番号に関するQ&A](https://www.ppc.go.jp/all_faq_index/faq1-q1-25/)を踏まえ、05では単体で個人情報となる個人識別符号を直接問う。銀行口座等も照合で個人情報になり得るため、選択肢ごとに常に個人情報でないとは断定しない。
- 演習問題③問9: 深層強化学習を通常の強化学習と区別できるよう、05の設問に深層ニューラルネットワークを使う条件を加える。
- 演習問題③問12: 取得元の4番はデータの前処理と人材雇用の要否を一文に混ぜている。05では品質確認・前処理なしにそのまま学習へ使えるという一つの誤りに絞る。
- 演習問題③問13: クラウドとオンプレミスのどちらが省エネルギーかを一律には決められない。05の誤答肢は、環境負荷を下げるにはクラウドから必ず切り替えるべきだという断定にする。
- 演習問題③問15: [BreimanのRandom Forests論文](https://doi.org/10.1023/A%3A1010933404324)を踏まえ、05では復元抽出による学習用標本の作成を問う。「木を異ならせるには異なるデータセットが必須」という取得元の断定を避ける。
- 演習問題③問16: [Vision Transformerの原著論文](https://arxiv.org/abs/2010.11929)では、大規模事前学習後にCNNと比較して良好な結果を示す。05では常にCNNより精度が高いとせず、画像パッチをTransformerで処理する構造を問う。
- 演習問題③問17: 標準RNNは長期依存関係の学習も苦手なため、取得元の3番は一般的な「欠点」を問うと紛らわしい。05の設問を時系列方向の並列処理に限定し、1番を一意の正答にする。
- 演習問題③問18: [経済産業省のAI開発契約ガイドライン](https://www.meti.go.jp/shingikai/sankoshin/shomu_ryutsu/joho_keizai/it_rikatsuyo/pdf/011_s02_02.pdf)はアセスメント段階での秘密保持契約を例示する。[秘密情報の管理資料](https://www.meti.go.jp/policy/economy/chizai/chiteki/pdf/handbook/chapter3.pdf)も終了時の返還・消去を扱う。05では締結時期を開発段階だけに遅らせず、終了後の取扱いを明確に定める選択肢を正答とする。
- 演習問題③問20: [NIST AI RMFの信頼性評価](https://airc.nist.gov/airmf-resources/airmf/3-sec-characteristics/)は安全以外にも複数の特性を扱う。05では倫理アセスメントの目的を事故防止だけに限定する誤りを明確にする。
- 演習問題③問24: 説明変数を増やせば未知データの予測精度が必ず上がるという取得元の趣旨を、05の誤答肢で明確にする。訓練データへの当てはまりと汎化性能を混同しない。
- 演習問題③問25: DAEを「画像生成には適用できない」とする取得元の解説は過度な断定である。[DAEを生成モデルとして扱う研究](https://arxiv.org/abs/1305.6663)もある。05ではVAE・Pix2Pix・CycleGANと比べ、DAEが主としてノイズ除去・再構成の手法である点を問う。後続03は生成不可能と書かない。
- 演習問題③問26: 形式知の量や整理も知識獲得の負担になり得るため、取得元の3番をそのまま誤答にはできない。[エキスパートシステムの知識獲得研究](https://www.sciencedirect.com/science/article/pii/0168169989900112)を踏まえ、05の3番を必要な形式知がすでに利用可能な状態へ直す。
- 演習問題③問29: 取得元が参照する[Google CloudのMLOps工程](https://docs.cloud.google.com/architecture/mlops-continuous-delivery-and-automation-pipelines-in-machine-learning)は、事業課題と成功基準を定めた後にデータ分析、学習、評価、監視へ進む。05ではその後のMLパイプライン工程を問う形に絞り、事業課題の分析自体をMLOps全体で不要とはしない。
