# G検定 試験概要

## 正本

- [JDLA公式 G検定](https://www.jdla.org/certificate/general/)
- 同ページ掲載の「G検定の試験出題範囲（シラバス）」第1.4版（2026年5月11日）

確認日: 2026-09-28

## 出題範囲

シラバスは技術分野と法律・倫理分野に分かれ、10の大項目と55の小項目を持つ。分類名は公式表記のまま使う。詳細は[カテゴリ準備](03_category_preparation.md)を参照する。

## 独自問題化で維持するG検定らしさ

定義、技術の特徴、手法の比較、適用例、法律・倫理上の考え方など、元の問題が問う判断を保つ。専門用語、正誤の決め手、難易度は変えない。問題文と選択肢を1問ずつ読み、語順や表現など必要な部分だけ自然に微改変する。選択肢を変えるときは、正答と各誤答の理由を再確認する。

取得元の出題領域ラベルは大項目の手掛かりとして使う。小項目は問題の内容と公式シラバスに基づいて決める。
