# eco検定の試験・入力概要

## 参照先

試験範囲は[東京商工会議所の公式試験要項](https://kentei.tokyo-cci.or.jp/eco/exam-info/)を正本とし、整備時に現行の公表内容を確認する。取得元の年版を、そのまま実施済み試験の年度又は現行法の基準日へ置き換えない。

以下は2026-10-25にKnounの実画面・原画像を確認した入力上の観察である。画像の保存と転記状態は[取得契約](../../../document/sources/knoun/source_contract.md)を参照する。

## 正誤を選ぶ入力

共通見出しと記述ラベルが同じ画像に含まれる。例えば模擬問題1の先頭では、内容が正しい記述を①、誤った記述を②で回答するよう指示されている。各画像の記述と指示を一緒に読む。他の出題でも番号の意味が同じだと決め付けない。

OCRは見出しの読み順を入れ替えたり、記述ラベルを落としたりする。共通見出しの「第1問」と、個別の記述ラベル（ア〜コ）を区別し、取得元の安定URLとの対応を保つ。

## 語群から空欄を選ぶ入力

同じ文章と語群が複数の画像に現れる場合がある。回答対象は、画像末尾の赤字にある「［ア］にあてはまる……」などの指示で確定する。共通文章内の空欄を全部まとめて回答する問題へ変換せず、その画像自身が指定する空欄と解説を対応付ける。同じ本文であることを理由に、異なる安定URLを統合しない。

語群が二列の場合も、画像に印字された丸数字と語句を一つずつ対応付ける。模擬問題1の`mondai1_11`には①〜⑮の15候補があり、OCRは②を①より前に置いたり、⑪〜⑮を別の文字又は一桁の丸数字と誤読したりする。テキストの出現順から候補番号を再生成しない。

共通見出しにある配点や記述数は、語群の候補数を表さない。末尾の対象空欄、本文中の同名空欄、当該画像の正答・解説を独立に確認する。

## 表記と独自問題化

CO₂などの下付き文字、数値範囲、年と年度、丸数字、否定、制度名を原画像と照合する。単なる紙面の折返しはつなげてよいが、空欄、段落、語群、図表の対応を失わせない。

05では、直接知識を問う形や語群による比較を維持し、元の正答と各誤答を分ける条件を確認する。文字だけのスキャンと、問題の成立に必要な図表を区別する。図表を含む問題の独自画像は、[共通の画像工程](../../../document/operations/original_question_authoring_workflow.md#画像の扱い)に従って確定する。
