# ネットワークスペシャリスト試験 補助ドキュメント

このディレクトリには、ネットワークスペシャリスト試験に固有の試験構造とカテゴリ設計資料を置きます。解説文の共通ルールは`prompt/03_prompt_add_explanationText.md`を使います。

## 資料

- `01_exam_profile.md`: 出題範囲、午前I・午前IIの性格、問題形式
- `03_category_preparation.md`: `category.json`を設計又は見直す場合の資料

## 解説の資格固有調整

- まず可用性、性能、セキュリティ、運用性などの要件を示し、その要件を満たす技術を結び付ける。似た技術は、層、役割、配置場所又は適用場面の違いで分ける。
