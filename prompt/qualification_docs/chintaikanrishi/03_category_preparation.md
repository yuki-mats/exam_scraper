# 賃貸不動産経営管理士のカテゴリ設計

## 根拠と構成

2026年10月3日にユーザーが提供した過去問集の目次画像6枚を分類の根拠とする。画像から書名、版、刊行年は確認できないため、特定の書籍名や年度を推定しない。

5章を5つのfolderに対応させ、内容が重なる小見出しを復習単元として統合した。第4章は2枚の画像を合わせて扱う。分類名、ID、個々の収録範囲と元見出しの対応は`output/chintaikanrishi/category/category.json`を正本とし、この文書には一覧を複製しない。

目次の94見出しを70 questionSetsへ対応付けた。各questionSetの`sourceHeadings`に元の見出しを保存する。同じ見出しが異なる章にある場合は、親folderと組み合わせて区別する。章末の「論点補充の一問一答」は出題形式を示すため、独立した分類にはしない。

括弧内の書籍収録問題数とページ番号はローカル過去問の件数ではない。`questionCount`は問題紐付け前の0とし、04工程後の実データから集計する。画像そのものはGitへ追加しない。

## 分類を分ける基準

問題文、全選択肢、正答と解説を一問ずつ確認し、その問を誤答した学習者が復習すべき主題で分類する。取得元の分野名、法令名やキーワードだけでは確定しない。`matchingHints`は候補を探すための補助情報である。

- 管理業の登録・業務規制、契約前の重要事項説明、締結時の書面交付は第1章へ置く。管理委託の標準契約書の条項は第3章へ置く。
- 特定賃貸借契約の広告・勧誘・説明規制は第1章、管理受託方式とサブリース方式の運用比較は第2章、特定賃貸借標準契約書の条項は第3章へ置く。
- 督促・未収賃料の回収、少額訴訟、執行、破産、残置物と原状回復ガイドラインは第2章の該当単元へ置く。賃貸借の一般的な権利義務、契約更新・解除や借地借家法は第3章へ置く。
- 第2章の賃貸住宅管理は管理計画・管理体制の運用、第1章の賃貸不動産管理は管理の目的・基本機能を扱う。具体的な手順や法定制度が主題なら、各章の専用単元を優先する。
- 災害への備えと管理者の緊急対応は第2章、耐震構造・診断・補強と応急危険度判定は第4章へ置く。
- 第4章の建物点検・定期調査・報告は建物全体、設備の検査・報告は設備固有の制度を扱う。個別設備の構造・機能・維持管理が主題なら、その設備単元を選ぶ。
- 防犯設計と住環境整備は第2章の住環境単元、防火を含む管理上の予防措置は同章の防犯・防火単元、消防法と消防設備は第4章へ置く。
- 第2章の関連法令は管理実務上の措置、第3章の関連法令は法令解釈を扱う。まず専用単元への所属を確認し、いずれも未分類問題の仮置き場にしない。主題を確定できない問題は保留する。
- 住生活基本計画と社会状況は第2章、個別事業の企画・収支・経営判断は第5章へ置く。

## 問題への紐付けと検証

今回の03cは分類正本の準備を担当する。既存の`00_source`は変更せず、問題の`questionSetId`付与は共通の04工程で一問ずつ行い、`22_questionSetId_linked`へ保存する。使用するIDはcategoryの`questionSets[].questionSetId`に限る。

作成後は[共通分類ポリシー](../category_taxonomy_policy.md#検証コマンド)のschema-only dry-runを実行する。04後のcoverage・count集計と公開検証は、問題側の成果物がそろった後に行う。
