# 賃貸不動産経営管理士の一次根拠

出題当時と現在の判定を分ける。公式の試験日は `document/sources/chintaikanrishi/official_exam_pdf_catalog.json` を参照する。過去問道場は現行制度に合わせて本文を更新することがあるため、当時の設問・回答の確認にはカタログの公式問題PDFと正解番号PDFを使う。取得元の解説は参照候補として扱い、現行法令の一次根拠に代用しない。

公式原文と現在の表示が異なることを判定根拠に使う場合は、公式PDFを実際に開き、対応する年度・問番号・選択位置を確認する。確認した問題PDFと正解番号PDFのURL、問題の掲載頁、原文と現在文の差を、監査sidecarの `sourceSummary` と該当肢の `lawRevisionFacts` の説明へ残す。資格資料に書かれた確認例だけを根拠に確定せず、独立した監査が保存済みの記録から同じ原文を取得し、時点別の判定を検証できる状態にする。

現在化の確認例として、[2019年公式問題PDF](https://www.chintaikanrishi.jp/assets/common/else/past_question_2019.pdf)の問15（冊子9頁、PDF11頁）では、選択肢1は使用貸借の成立に建物の引渡しを要し、賃貸借では要しないという対比である。過去問道場の現在の同じ選択位置は、使用貸借も引渡しを成立要件としない記述へ変更されている。公式[正解番号PDF](https://www.chintaikanrishi.jp/assets/common/else/past_answer_2019.pdf)の問15は3である。当時の原文を旧民法593条へ、現在の表示を現行593条へ独立に照合し、同じ選択位置の現在化を確認する。現在化後の文言を旧法へそのまま当てはめて公式正解と衝突したと判断せず、試験当時の正答と現在の正答を別に記録する。これは公式PDFと現行ページの双方を確認した差分であり、原文を推測したものではない。

使用貸借の成立と終了は別の論点である。同じ問15の選択肢4の期間満了・返還には民法597条を確認し、成立に関する593条だけを根拠にしない。e-Govの[2019年4月1日時点の民法XML](https://laws.e-gov.go.jp/api/2/law_file/xml/129AC0000000089?asof=2019-04-01)と[2026年10月4日時点の民法XML](https://laws.e-gov.go.jp/api/2/law_file/xml/129AC0000000089?asof=2026-10-04)から、597条の見出しと本文をそれぞれ確認できる。旧条文は返還時期、現行条文は期間満了等による終了を規定しているため、同じ条番号で本文が不変だったとは記録しない。法令の基準日は公式問題PDFの試験条件を確認し、試験日そのものと区別する。

同様に、[2015年公式問題PDF](https://www.chintaikanrishi.jp/assets/common/else/past_question_2015.pdf)の問19（冊子9頁、PDF11頁）の選択肢4は、当時の賃貸住宅管理業者登録制度で借主への更新書面の交付を必要とする記述である。現在の過去問道場では、賃貸住宅管理業法による借主への更新書面交付義務はないという記述へ変更されている。貸主との管理受託契約書面と借主への書面を混同せず、当時の登録制度と現行の管理業法を区別する。公式[正解番号PDF](https://www.chintaikanrishi.jp/assets/common/else/past_answer_2015.pdf)の問19は2である。選択肢4は主体となる制度と述語の双方が現在化されているため、現在の否定文を旧制度へ当てはめて当時の誤答肢を増やさない。公式原文と現在文を独立に確認し、それぞれの正誤と正答位置の変化を記録する。

管理業・特定賃貸借契約の規制は、e-Govの賃貸住宅管理業法と施行規則に加え、国土交通省の[法令・解釈・監督処分基準の案内](https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/const/tochi_fudousan_kensetsugyo_const_tk3_000001_00004.html)から、論点に応じた資料を読む。条文で定める義務と、行政処分の運用基準を区別する。

旧登録制度を指定する問題では、国土交通省の[登録規程・業務処理準則・通達の保存ページ](https://www.mlit.go.jp/totikensangyo/const/sosei_const_fr3_000012.html)から、出題時点に対応する資料を読む。例えば[平成28年改正後の業務処理準則](https://www.mlit.go.jp/common/001143291.pdf)と[解釈・運用の考え方](https://www.mlit.go.jp/common/001152882.pdf)では、重要事項の説明、成立時書面、借主への更新書面をそれぞれ区別して確認できる。平成28年改正の適用前の試験には、保存ページの改正経緯から旧規定を確認する。旧制度は令和3年6月15日に廃止されているため、旧制度を指定した設問へ現在の管理業法の義務をそのまま当てはめない。取得元が設問自体を現行制度へ変更した場合は、公式問題PDFとの文面の差を先に確定する。

廃止済みの制度を明示してその当時の内容を問う記述は、制度が廃止されたことだけを理由に誤りへ変更しない。まず問題文が旧制度の事実を問うのか、現行制度の義務を問うのかを確定し、各時点の根拠と照合する。例えば[2015年公式問題PDF](https://www.chintaikanrishi.jp/assets/common/else/past_question_2015.pdf)の問6（冊子3頁、PDF5頁）は第8条の「8条報告」を問い、[公式正解番号PDF](https://www.chintaikanrishi.jp/assets/common/else/past_answer_2015.pdf)では第3肢が正解である。取得元の表示は旧制度の第9条に基づく「9条報告」へ改題されている。[第8条の報告様式](https://www.mlit.go.jp/common/000167443.pdf)と[第9条の報告様式](https://www.qsr.mlit.go.jp/n-park/construction/reigyoumuhoukoku.pdf)には、ともに「受託戸数」の欄がある。この第3肢は旧制度内の報告対象を述べており、現行法第20条の委託者への定期報告に読み替えて誤りと判定しない。改題で条番号が変わった事実、旧制度の廃止、現行制度との違いは、正誤判定と混ぜずに解説と監査記録へ明示する。

同じ2015年公式問題PDFの問4（冊子2頁、PDF4頁）第4肢は、旧登録制度に基づく「罰則」を問う。[制定時の賃貸住宅管理業者登録規程](https://www.mlit.go.jp/common/000167746.pdf)は、第11条で指導・助言・勧告、第12条第1項第8号で情状が特に重い場合等の登録抹消を定めている。登録抹消を刑罰と混同せず、旧登録規程全体の規定を確認して第4肢を判定する。[公式正解番号PDF](https://www.chintaikanrishi.jp/assets/common/else/past_answer_2015.pdf)では問4の正解は第3肢である。正答番号だけから第4肢の理由を逆算せず、規程にある行政上の措置と選択肢が述べる罰則の違いを記録する。現行法に刑事罰の規定があっても、この選択肢が指定する旧登録制度に罰則があったことにはならない。同じ理由で、第2肢の旧登録制度におけるサブリース業者の対象範囲も、現行法の定義へ読み替えて正誤を反転させない。

例えば監督処分の対象となる違反行為の遡及期間は、法第22条・第23条だけでは確認できない。[賃貸住宅管理業者の違反行為に対する監督処分の基準](https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/const/content/001406101.pdf)の「Ⅰ 通則」「2 監督処分の内容の決定」「2-1 監督処分内容の決定手続」「(1)」にある原則として処分前5年間という基準を確認する。条文に年数が見当たらないことだけから記述を誤りと判断しない。資料の適用時点と例外も確認する。

個数・組合せ問題は各記述を独立に判断した後、その結果と元の回答を照合する。元の個数から各記述の真偽を逆算しない。統計や政策目標は指定された年度の公式資料を確認し、現在の統計へ置き換えない。

更新料の有効性は、契約一般が口頭でも成立することと、消費者契約法10条による不当条項の審査を分ける。国土交通省の[民間賃貸住宅に関する相談対応事例集](https://www.mlit.go.jp/jutakukentiku/house/content/001493363.pdf)「10 最近の最高裁判例」「事例4」（冊子165〜167頁、PDF177〜179頁）で、平成23年7月15日最高裁判決の事案と判断を確認する。同判決が有効としたのは契約書に内容が一義的かつ具体的に記載された更新料条項であり、書面の条項を欠く口頭の了承だけを同じ条件とみなしてはならない。口頭だから常に無効とも断定せず、契約締結の経緯・情報と交渉力の格差などを総合して判断するという判旨を読む。設問が「最も不適切」を問う場合は、各記述の条件を比較し、十分な条件を示さず一律に請求可能とする記述と、判決の射程との違いを説明する。公式正解番号は独立に照合し、番号に合わせて法理を変更しない。

公式問題冊子の法令基準日は試験日と異なる。2015～2025年の冊子冒頭の注意事項を確認し、各年4月1日を共通基準日として[公式資料catalog](../../../document/sources/chintaikanrishi/official_exam_pdf_catalog.json)の`lawBasisDates`へ記録している。2021年の注意事項7は賃貸住宅管理業法に限り2021年6月15日を指定するため、同法の例外は`lawBasisDateOverrides`に保持する。各問で施行日等を明示する例外があればその問題文を優先し、根拠候補の`exam_time_basis.referenceDate`、原文に対する判定、現行法の判定を独立に確認する。
