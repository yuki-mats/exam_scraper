# 賃貸不動産経営管理士の一次根拠

出題当時と現在の判定を分ける。公式の試験日は `document/sources/chintaikanrishi/official_exam_pdf_catalog.json` を参照する。過去問道場は現行制度に合わせて本文を更新することがあるため、当時の設問・回答の確認にはカタログの公式問題PDFと正解番号PDFを使う。取得元の解説は参照候補として扱い、現行法令の一次根拠に代用しない。

管理業・特定賃貸借契約の規制は、e-Govの賃貸住宅管理業法と施行規則に加え、国土交通省の[法令・解釈・監督処分基準の案内](https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/const/tochi_fudousan_kensetsugyo_const_tk3_000001_00004.html)から、論点に応じた資料を読む。条文で定める義務と、行政処分の運用基準を区別する。

例えば監督処分の対象となる違反行為の遡及期間は、法第22条・第23条だけでは確認できない。[賃貸住宅管理業者の違反行為に対する監督処分の基準](https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/const/content/001406101.pdf)の「Ⅰ 通則」「2 監督処分の内容の決定」「2-1 監督処分内容の決定手続」「(1)」にある原則として処分前5年間という基準を確認する。条文に年数が見当たらないことだけから記述を誤りと判断しない。資料の適用時点と例外も確認する。

個数・組合せ問題は各記述を独立に判断した後、その結果と元の回答を照合する。元の個数から各記述の真偽を逆算しない。統計や政策目標は指定された年度の公式資料を確認し、現在の統計へ置き換えない。
