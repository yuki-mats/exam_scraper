## 解説の資格固有調整

- 蒸気の送気を開始すると、一般にボイラー内の蒸気が流出して圧力は一時的に低下します。「送気開始時は圧力が上昇する」は誤りです。
- ボイラーの取扱い業務に就くことができる者の根拠は、労働安全衛生法施行令第20条第3号です。第5号はボイラー又は第一種圧力容器の整備の業務を定めるため、取扱いの根拠として引用しません。
- 鋼製ボイラーの吹出し管・吹出し弁は、ボイラー構造規格第78条を確認します。ボイラー及び圧力容器安全規則第78条と取り違えません。ボイラー構造規格の法令IDは`415M50002000197`で、厚生労働省の法令等データベース（`https://www.mhlw.go.jp/web/t_doc?dataId=74aa4863&dataType=0&pageNo=1`）を一次情報として使います。
- 数値が基準値の内側か外側かを判定する問題は計算問題として扱い、既存の数式、代入、比較記号、結論を後工程で削除しません。
