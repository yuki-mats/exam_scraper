# 一級ボイラー技士 `category.json` 準備メモ

## 分類の正本

- 共通方針は [category_taxonomy_policy.md](/Users/yuki/development/exam_scraper_work/prompt/qualification_docs/category_taxonomy_policy.md) とする。
- 公式の上位分類は、公益財団法人安全衛生技術試験協会「一級ボイラー技士の紹介」の試験科目を使う。
- 公式試験科目は「ボイラーの構造に関する知識」「ボイラーの取扱いに関する知識」「燃料及び燃焼に関する知識」「関係法令」の4科目である。
- `output/boiler1/category/category.json` はこの4科目をfoldersとし、2009-1〜2025-2の`00_source`全34回、計1,360問の`category`と`sourceTopic`を復習単位へ整理したものとする。

## 粒度と境界

- folderは公式試験科目に対応させる。年度、試験区分、問題番号はfolderやquestionSetにしない。
- questionSetは、誤答した受験者が戻って学ぶ範囲で切る。sourceTopicの年度別表記は統合し、1問だけの特殊論点は近接する復習単位へ寄せる。
- 問題文の主題がボイラー本体の構造・性能なら「ボイラーの構造」、運転・点検・水質なら「ボイラーの取扱い」とする。燃料の性質・燃焼装置・燃焼計算・排出物は「燃料及び燃焼」とする。
- 法令上の基準、資格、検査、届出、管理義務は「関係法令」へ寄せる。技術知識として同じ装置を扱う問題でも、法令上の要件を問う場合は構造・取扱いへ重ねない。
- 構造科目の燃料低発熱量や効率の計算は、出題時の公式categoryを維持し、構造科目の「性能・熱回収・計算」へ分類する。燃料の性質や燃焼計算そのものは燃料及び燃焼へ分類する。

## 更新時の注意

- `questionSetId`は04で一問ずつ付与する。この03c工程では問題JSON、既存ID、`00_source`を変更しない。
- `category.json`を更新した場合は、問題側成果物を要求しないschema-only dry-runを実行する。Firestoreへのアップロードは行わない。
