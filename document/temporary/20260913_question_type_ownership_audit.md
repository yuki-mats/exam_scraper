# questionTypeの判定・保存経路の点検（2026-09-13）

## 結論

通常の一問整備は既に工程別の書込fieldを分離しており、後工程の候補に`questionType`を追加・削除する権限はない。一方、分類基準の重複、取得時の推測、旧移行処理の逆生成、現在値を前提とする評価指示が残っていた。これらを整理した。過去の特定の変更がどの実行経路で生じたかまでは、Git差分だけでは断定していない。

## 確認範囲と修正

`prompt/`（資格別を含む）、`config/`、`tools/`、`scripts/`、root scraper及び現行の運用・field契約を横断検索し、分類を設定する箇所と形式を読み取るだけの箇所を区別した。過去の作業記録や生成済み問題データは現行の分類ルールとして採用しない。
